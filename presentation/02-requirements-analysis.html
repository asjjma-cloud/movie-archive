아키텍처 다이어그램

[사용자] ➔ [View / UI] ➔ [Controller] ➔ [Service] ➔ [DB]
  • 사용자: 아카이브 및 리뷰 컨트롤 주체
  • View/UI: Java Swing 기반 윈도우 인터페이스
  • Controller: 라우팅, 인증 상태 제어 및 검증
  • Service: 트랜잭션 단위 비즈니스 로직 처리
  • DB: SQLite 임베디드 관계형 데이터 영속화
