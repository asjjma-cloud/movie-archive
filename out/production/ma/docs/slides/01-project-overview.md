# 01. Project Overview

## 프로젝트 소개

**Movie Archive**는 영화 감상 기록을 체계적으로 관리할 수 있는 Java 기반 데스크톱 애플리케이션입니다.

---

## 개발 목적

- 영화 감상 기록을 체계적으로 관리
- 리뷰와 별점을 남기며 감상 기록 공유
- Java 수업에서 배운 개념을 실제 프로젝트에 적용
