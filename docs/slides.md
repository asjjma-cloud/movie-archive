## 01. 프로젝트 개요

- **목적**: 영화 감상 기록 관리 서비스
- **기간**: 2026.04.27 ~ 2026.06.15
- **팀**: Archimoo (최영재, 남하경)

| 분류 | 기술 |
|------|------|
| Language | Java 17 |
| UI | Java Swing |
| DB | SQLite |
| 연동 | JDBC |
| 암호화 | SHA-256 |

## 02. 시스템 구조

4계층 아키텍처
---

## 03. 주요 기능 (1/2)

### 🔐 회원 인증
- 회원가입 / 로그인 / 로그아웃
- 아이디·이메일 중복 검증
- SHA-256 비밀번호 암호화

### 🎥 영화 조회
- 전체 목록 조회
- 제목·감독 검색 (엔터키 지원)
- 장르 필터링
- 컬럼 헤더 클릭 정렬

---

## 03. 주요 기능 (2/2)

### ⭐ 리뷰 & 별점
- 별점 1~5점 작성 (JSlider)
- 중복 리뷰 방지
- 평균 별점 실시간 갱신

### 🛡 관리자
- 영화 추가 / 삭제
- 회원 목록 조회 / 계정 정지

---

## 04. DB 설계
| 테이블 | 주요 컬럼 |
|--------|-----------|
| users | id, username, email, password(SHA-256), role |
| movies | id, title, director, genre, release_year |
| reviews | id, user_id(FK), movie_id(FK), rating, content |

---

## 05. 핵심 구현 포인트

| 항목 | 내용 |
|------|------|
| SHA-256 | 비밀번호 해시 처리 |
| 싱글톤 DB | DBConnection 단일 관리 |
| Stream API | 평균 별점 계산 |
| TableRowSorter | 컬럼 정렬 |
| 실시간 갱신 | 리뷰·닉네임 즉시 반영 |
